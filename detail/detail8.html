Everlast Booking System

A comprehensive web application tailored for a photography and videography business, featuring automated bookings, online payments, and integrated scheduling.

About The Project

Everlast Booking System is an end-to-end management platform designed specifically for a photography studio. It replaces manual booking processes with a seamless, fully automated digital workflow.

Key features include a dynamic frontend for clients to view portfolios and book packages, secure payment gateway integration via Midtrans (handling down payments and full payments), and automated real-time scheduling using the Google Calendar API. The system also includes a robust admin dashboard with a fully automated Cash Flow management module to track income and freelancer expenses accurately.
