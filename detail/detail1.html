Lokal Freelance Marketplace

A comprehensive platform connecting local talent with businesses, featuring secure payments and project management tools.

About The Project

The goal of this project was to create a reliable and user-friendly marketplace for freelancers in Padang. The platform needed to handle user registration, project listings, secure bidding, and integrated payments via Midtrans.

I was responsible for the full development cycle, from database design and backend logic with Laravel to crafting a responsive frontend that works seamlessly across all devices.
