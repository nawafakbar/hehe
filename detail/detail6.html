About The Project

This project was created entirely within Figma, encompassing both the visual design (UI) and a fully interactive prototype. The primary goal was to craft a modern interface that aligns with established UX best practices.

The process involved user flow mapping, wireframing, and high-fidelity mockups to ensure a smooth and intuitive user interaction from start to finish.
