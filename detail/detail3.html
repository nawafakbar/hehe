Questionnaire Website

An interactive web-based platform for creating, distributing, and analyzing survey data with a responsive design.

About The Project

This project was developed to facilitate data collection through online questionnaires. It allows administrators to create surveys and users to submit their responses easily.

The application was developed using native PHP and MySQL for robust database management, with Bootstrap enhancing the responsive design to ensure a great user experience on any device.
